# mycroblog mobile

Native iOS and Android clients for [mycroblog](https://github.com/mycroblog/my), a microblog for the fediverse.

The iOS app lives under `app/ios` and the Android app under `app/and`. Design decisions are in
[docs/adr/](docs/adr/).
