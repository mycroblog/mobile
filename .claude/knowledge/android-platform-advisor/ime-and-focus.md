# IME insets, focus, keyboard (checked 2026-11-28)

- Edge-to-edge setup page step 2: set android:windowSoftInputMode="adjustResize" on the activity "to receive IME insets"; enforcement at targetSdk 35 does not replace it [https://developer.android.com/develop/ui/compose/system/setup-e2e, 2026-11-28]
- windowSoftInputMode default adjustUnspecified: system picks resize if the window has scrollable layout views, else pan; adjustPan pans so the focus is not obscured; adjustNothing leaves it to window insets -> a Compose-only window can get a pan with the default [https://developer.android.com/guide/topics/manifest/activity-element, 2026-11-28]
- KeyboardOptions (foundation 1.10) has capitalization, autoCorrectEnabled, keyboardType, imeAction, platformImeOptions (private IME commands), showKeyboardOnFocus, hintLocales: no extract-UI flag; IMEs treat options as best effort; Compose input session supports extracted-text updates [https://developer.android.com/reference/kotlin/androidx/compose/foundation/text/KeyboardOptions, AndroidTextInputSession.android.kt androidx-main, 2026-11-28]
- SoftwareKeyboardController.hide() is best effort, a side effect (not in recomposition); docs: keyboard "is automatically shown and hidden by focus events in the BasicTextField"; FocusManager.clearFocus documents focus only [https://developer.android.com/reference/kotlin/androidx/compose/ui/platform/SoftwareKeyboardController, https://developer.android.com/reference/kotlin/androidx/compose/ui/focus/FocusManager, 2026-11-28]
