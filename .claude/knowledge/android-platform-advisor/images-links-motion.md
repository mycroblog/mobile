# Images, links, motion

- Coil 3.6.3 (2026-09-18, latest): `io.coil-kt.coil3:coil-compose`, `coil-network-okhttp` (OkHttp fetcher, needed for URLs), `coil-gif`, all 3.6.3 [https://coil-kt.github.io/coil/getting_started/, https://coil-kt.github.io/coil/changelog/, checked 2026-11-28]
- coil-gif: `AnimatedImageDecoder` (API 28+, also animated WebP/HEIF), `GifDecoder` (all APIs, slower); detected by header once the artifact is added; `repeatCount(Int)` per request or loader, `ENCODED_LOOP_COUNT` = -2; the meaning of 0 and a static first frame are NOT documented by Coil [https://coil-kt.github.io/coil/gifs/, https://coil-kt.github.io/coil/api/coil-gif/coil3.gif/, checked 2026-11-28]
- Coil `ImageRequest.Builder.decoderFactory(Decoder.Factory)` overrides the registry for one request; `coil3.decode.BitmapFactoryDecoder.Factory()` exists; that it yields a GIF first frame is NOT confirmed [https://coil-kt.github.io/coil/api/coil-core/coil3.request/-image-request/-builder/decoder-factory.html, checked 2026-11-28]
- Coil `AsyncImage` takes `placeholder`/`error`/`fallback` as Painter; Coil documents no Bitmap form, build a Painter yourself [https://coil-kt.github.io/coil/compose/, checked 2026-11-28]
- androidx.browser 1.10.0 stable (2026-03-25); `CustomTabsIntent.Builder().build().launchUrl(context, uri)`; with no Custom Tabs browser the default browser opens the ACTION_VIEW; with no browser at all ActivityNotFoundException, catch it [https://developer.android.com/jetpack/androidx/releases/browser, https://developer.chrome.com/docs/android/custom-tabs/guide-get-started, https://developer.android.com/training/package-visibility/use-cases, checked 2026-11-28]
- Android 11+: opening a URL with startActivity or a Custom Tab needs no `<queries>`; only a prior browser check (queryIntentActivities, `CustomTabsClient.getPackageName`) needs an ACTION_VIEW BROWSABLE https `<intent>` or the CustomTabsService action [https://developer.android.com/training/package-visibility/use-cases, checked 2026-11-28]
- "Remove animations" (AOSP Settings, DisableAnimationsPreferenceController) writes 0.0 to window_animation_scale, transition_animation_scale and animator_duration_scale (1.0 when off); apps may read Settings.Global.ANIMATOR_DURATION_SCALE [https://android.googlesource.com/platform/packages/apps/Settings/+/refs/heads/main/src/com/android/settings/accessibility/DisableAnimationsPreferenceController.java, https://developer.android.com/reference/android/provider/Settings.Global, checked 2026-11-28]
- `ValueAnimator.areAnimatorsEnabled()` (API 26) is false when the animator duration scale is 0 or Battery Saver is on; the docs offer it to pick another experience; it reads only the animator scale [https://developer.android.com/reference/android/animation/ValueAnimator, checked 2026-11-28]
