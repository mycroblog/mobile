# Instrumented tests, Ktor JVM engine, Gradle Test inputs (checked 2026-11-27)

- Compose: androidTestImplementation ui-test-junit4; debugImplementation ui-test-manifest is needed for createComposeRule, not for createAndroidComposeRule<Activity>() [https://developer.android.com/develop/ui/compose/testing, 2026-11-27]
- Hilt: HiltTestApplication and a custom runner are only for tests with @HiltAndroidTest; without Hilt test APIs the real @HiltAndroidApp application runs under the default AndroidJUnitRunner [https://developer.android.com/training/dependency-injection/hilt-testing, 2026-11-27]
- AGP 9.0 flips android.default.androidx.test.runner to true: testInstrumentationRunner defaults to androidx.test.runner.AndroidJUnitRunner [https://developer.android.com/build/releases/agp-9-0-0-release-notes, 2026-11-27]
- androidx.test stable: runner 1.7.0, ext:junit 1.3.0, core 1.7.0, espresso 3.7.0, rules 1.7.0 (all 2025-07-30); 1.8/3.8 are alpha [https://developer.android.com/jetpack/androidx/releases/test, 2026-11-27]
- `connectedAndroidTest` / `connected<Variant>AndroidTest` run on every connected device; ANDROID_SERIAL is documented only for adb, AGP honoring it is not confirmed [https://developer.android.com/studio/test/command-line, https://developer.android.com/studio/command-line/variables, 2026-11-27]
- Ktor client engines: JVM Apache5, Java (JDK 11+, HTTP/2, WebSockets), Jetty; OkHttp (JVM+Android); CIO multiplatform, HTTP/1.x only, lowest auto-selection priority; ktor-client-java 3.6.1 exists [https://ktor.io/docs/client-engines.html, https://repo1.maven.org/maven2/io/ktor/ktor-client-java/maven-metadata.xml, 2026-11-27]
- Gradle Test: inputs.dir(..).withPropertyName(..).withPathSensitivity(RELATIVE) is the runtime API; a CommandLineArgumentProvider in jvmArgumentProviders is tracked via @Nested; the runtime API has no @Nested; Tasks must not use Project at execution time (configuration cache) [https://docs.gradle.org/current/userguide/incremental_build.html, https://docs.gradle.org/current/userguide/configuration_cache_requirements.html, 2026-11-27]
- Roborazzi's own plugin configures AGP tests via tasks.withType(Test) with inputs.files(..).withPathSensitivity(RELATIVE) and systemProperties [https://github.com/takahirom/roborazzi/blob/main/include-build/roborazzi-gradle-plugin/src/main/java/io/github/takahirom/roborazzi/RoborazziPlugin.kt, 2026-11-27]
