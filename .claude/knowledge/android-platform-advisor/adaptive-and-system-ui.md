# Adaptive navigation, back, edge-to-edge (checked 2026-11-27)

- NavigationSuiteScaffold default layoutType = calculateFromAdaptiveInfo: NavigationBar if width or height is compact or tabletop, else NavigationRail (never a drawer); navigationSuiteType() (material3 1.4+) gives ShortNavigationBar compact/medium-height, WideNavigationRailCollapsed otherwise; a permanent drawer must be set by layoutType [https://developer.android.com/develop/ui/compose/layouts/adaptive/build-adaptive-navigation, AndroidX source NavigationSuiteScaffold.kt androidx-main, 2026-11-27]
- NavigationBar "should contain three to five" items; the scaffold does not truncate, limit items yourself [https://developer.android.com/reference/kotlin/androidx/compose/material3/NavigationBar.composable, 2026-11-27]
- Predictive back: android:enableOnBackInvokedCallback on <application> is the opt-out flag; targeting 36 on Android 16+ turns system animations on by default and onBackPressed is not called; OnBackPressedCallback always works [https://developer.android.com/about/versions/16/behavior-changes-16, https://developer.android.com/guide/navigation/custom-back/predictive-back-gesture, 2026-11-27]
- Navigation3 1.2.0 NavDisplay animates predictive back (predictivePopTransitionSpec) and adds NavigationBackHandler on NavigationEvent [https://developer.android.com/jetpack/androidx/releases/navigation3, 2026-11-27]
- Edge-to-edge is enforced at targetSdk 35+; "Call enableEdgeToEdge to make this backward compatible"; opt-out attr is disabled at target 36 on Android 16 [https://developer.android.com/develop/ui/compose/system/system-bars, https://developer.android.com/about/versions/16/behavior-changes-16, 2026-11-27]
- NavigationRail(modifier, containerColor, contentColor, header: (ColumnScope.() -> Unit)?, windowInsets, content: ColumnScope.() -> Unit) is a fillMaxHeight Column with windowInsetsPadding, spacedBy arrangement, no scrolling; put `Column(Modifier.weight(1f).verticalScroll(state))` in content so header and insets stay fixed; WideNavigationRail has no verticalScroll either [https://android.googlesource.com/platform/frameworks/support/+/refs/heads/androidx-compose-material3-release/compose/material3/material3/src/commonMain/kotlin/androidx/compose/material3/NavigationRail.kt, release branch not the 1.5.0 tag, 2026-11-27]
- Custom suite: NavigationSuiteScaffoldLayout(navigationSuite, layoutType, state, content) is public and does not consume window insets for content (the scaffold does it via a private modifier) -> consumeWindowInsets yourself; NavigationSuiteScaffold(navigationItems: @Composable () -> Unit, navigationSuiteType, ..., primaryActionContent) takes composable items [https://android.googlesource.com/platform/frameworks/support/+/refs/heads/androidx-compose-material3-release/compose/material3/material3-adaptive-navigation-suite/src/commonMain/kotlin/androidx/compose/material3/adaptive/navigationsuite/NavigationSuiteScaffold.kt, 2026-11-27]
- NavigationBarItem sizes itself by icon plus label height and measures the label with loose width, so a wrapped label raises that item and moves its icon up; one-line labels keep icons level; alwaysShowLabel=false centers the icon of unselected items; doc: five items show labels if space permits [https://android.googlesource.com/platform/frameworks/support/+/refs/heads/androidx-compose-material3-release/compose/material3/material3/src/commonMain/kotlin/androidx/compose/material3/NavigationBar.kt, 2026-11-27]
