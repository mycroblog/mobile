# Sign-in with App Links and Custom Tabs

- Verification fetches `https://HOST/.well-known/assetlinks.json` per intent-filter host (VIEW + BROWSABLE + DEFAULT + http/https, autoVerify); wait 20 s after install [https://developer.android.com/training/app-links/verify-android-applinks, checked 2026-11-27]
- File: content-type application/json, HTTPS even if filters say http, no 301/302 redirect, one file per host; sha256_cert_fingerprints takes several (debug + release); keytool -list -v -keystore K gives the SHA256 [https://developer.android.com/training/app-links/configure-assetlinks, checked 2026-11-27]
- Test on Android 12+ (any target): `pm set-app-links --package P 0 all` (reset), `pm verify-app-links --re-verify P`, wait minutes, `pm get-app-links P` (verified/none/legacy_failure/1024+ = verifier error); `--user cur` adds the user selection; device needs internet [https://developer.android.com/training/app-links/verify-android-applinks, checked 2026-11-27]
- Update latency: Android 15+ re-verifies periodically, changes take up to 7 days; 14 and lower only on install/update; reinstall forces a check but server-side caches can delay a few hours [https://developer.android.com/training/app-links/verify-android-applinks, checked 2026-11-27]
- Unverified link: deep link is subject to the disambiguation dialog; user can approve in Open by default settings (one app per domain) [https://developer.android.com/training/app-links, https://developer.android.com/training/app-links/verify-android-applinks, checked 2026-11-27]
- Auth Tab: androidx.browser 1.9.0 (stable 2025-07-30; latest 1.10.0), Chrome 137+, else falls back to a Custom Tab; https redirect via launch(launcher, url, redirectHost, redirectPath) needs Digital Asset Links, result in ActivityResultCallback (RESULT_OK/CANCELED/VERIFICATION_FAILED/VERIFICATION_TIMED_OUT) [https://developer.android.com/reference/androidx/browser/auth/AuthTabIntent, https://developer.android.com/jetpack/androidx/releases/browser, https://developer.chrome.com/docs/android/custom-tabs/guide-auth-tab, checked 2026-11-27]
- Auth Tab: register the launcher unconditionally before the activity is created; on fallback the result may come to the callback or the Activity intent, so handle both; the guide does not cover process death [https://developer.chrome.com/docs/android/custom-tabs/guide-auth-tab, checked 2026-11-27]
