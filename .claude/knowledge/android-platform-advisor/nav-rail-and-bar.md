# Navigation rail and bar details (checked 2026-11-27)

- NavigationRail is a fillMaxHeight Column with windowInsetsPadding(systemBarsForVisualComponents Vertical+Start) and spacedBy; no scroll, no custom Layout; NavigationSuiteScaffoldLayout measures navigationSuite in a Box with loose constraints (min 0, max = window) and places it at (0,0) -> source predicts a weight+verticalScroll Column inside works, a report says it did not (unresolved); the insets are zero if an ancestor consumed them [https://android.googlesource.com/platform/frameworks/support/+/refs/heads/androidx-compose-material3-release/compose/material3/material3/src/commonMain/kotlin/androidx/compose/material3/NavigationRail.kt, .../NavigationSuiteScaffold.kt, release branch, 2026-11-27]
- NavigationBarItem sizes itself by icon plus label height and measures the label with loose width: a wrapped label raises that item and moves its icon up; one-line labels keep icons level; alwaysShowLabel=false centers unselected icons [https://android.googlesource.com/platform/frameworks/support/+/refs/heads/androidx-compose-material3-release/compose/material3/material3/src/commonMain/kotlin/androidx/compose/material3/NavigationBar.kt, 2026-11-27]
- Material Components labelVisibilityMode AUTO = labeled up to 3 items, selected-only from 4; labels one line by default (labelMaxLines); SELECTED and UNLABELED modes exist [https://raw.githubusercontent.com/material-components/material-components-android/master/docs/components/BottomNavigation.md, 2026-11-27]
- m3.material.io navigation bar pages (guidelines, accessibility) cannot be fetched as text: M3 wording on truncation and font scale is unconfirmed [2026-11-27]
