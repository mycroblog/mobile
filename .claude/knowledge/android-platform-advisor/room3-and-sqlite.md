# Room 3 and SQLite drivers

- Plugin: `id("androidx.room3") version "3.0.3"` (same version as Room); `room3 { schemaDirectory("$projectDir/schemas") }` is required once applied; without the plugin `@Database(exportSchema = true)` is the default and exports only when the KSP arg `room.schemaLocation` is set [https://developer.android.com/jetpack/androidx/releases/room3, https://developer.android.com/reference/kotlin/androidx/room3/Database, checked 2026-11-28]
- Builders: `Room.databaseBuilder<T>(context, name)`, `Room.inMemoryDatabaseBuilder<T>()` (no Context; optional `factory` lambda, reflection by default); `.setDriver(...)` is mandatory [https://developer.android.com/reference/kotlin/androidx/room3/Room, https://developer.android.com/kotlin/multiplatform/room, checked 2026-11-28]
- Drivers: `androidx.sqlite:sqlite-bundled` (BundledSQLiteDriver, recommended) or `sqlite-framework` (AndroidSQLiteDriver, OS SQLite); both 2.7.1 stable, 2026-09-09 [https://developer.android.com/kotlin/multiplatform/sqlite, https://developer.android.com/jetpack/androidx/releases/sqlite, checked 2026-11-28]
- Bundled on a host JVM: docs list "JVM (Desktop)"; the sqlite-bundled-jvm 2.7.1 jar holds natives for linux_x64, linux_arm64, osx_arm64, windows_x64 (no osx_x64); the Android variant is an AAR with jni/ ABIs only, so an Android module's unit-test classpath probably cannot load it; NOT confirmed by a doc or a run [https://dl.google.com/dl/android/maven2/androidx/sqlite/sqlite-bundled/2.7.1/sqlite-bundled-2.7.1.module, checked 2026-11-28]
- Writes: `@Upsert` and `@Transaction` work on suspend DAO functions (Transaction wraps the body; Insert/Update/Delete/Upsert are already transactional); `db.withWriteTransaction { }` (IMMEDIATE) replaces runInTransaction/withTransaction; `useWriterConnection { it.immediateTransaction { } }` is the lower level; 3.0.2 and 3.0.3 fix a deadlock and an IllegalMonitorStateException of `@Transaction` wrappers [https://developer.android.com/reference/kotlin/androidx/room3/Transaction, https://developer.android.com/reference/kotlin/androidx/room3/package-summary, checked 2026-11-28]
