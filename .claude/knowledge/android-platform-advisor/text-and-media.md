# Rich text, inline images, links, media

- `AnnotatedString.fromHtml(html, linkStyles, linkInteractionListener)` is an Android-only extension in ui-text (since 1.7.0) over `HtmlCompat.fromHtml` (Spanned, platform XML parser); it keeps b/i/u/s/sup/sub/font/span style/p/div/br/ul/li and `<a>` as `LinkAnnotation.Url`, but drops `class` attributes -> mention/hashtag/invisible/ellipsis spans cannot be told apart; parse the server HTML ourselves [https://developer.android.com/reference/kotlin/androidx/compose/ui/text/AnnotatedString.Companion, https://android.googlesource.com/platform/frameworks/support/+/refs/heads/androidx-main/compose/ui/ui-text/src/androidMain/kotlin/androidx/compose/ui/text/Html.android.kt, checked 2026-11-28]
- `AnnotatedString.Saver` drops LinkInteractionListener, so a saved string loses click handlers; links with null listener open through LocalUriHandler [https://developer.android.com/reference/kotlin/androidx/compose/ui/text/AnnotatedString.Companion, checked 2026-11-28]
- Multiple links in one Text: `withLink(LinkAnnotation.Url(url, TextLinkStyles(style = SpanStyle(...))))` or `LinkAnnotation.Clickable`; TextLinkStyles also takes focused/hovered/pressed styles [https://developer.android.com/develop/ui/compose/quick-guides/content/support-multiple-links, checked 2026-11-28]
- Each link is a clickable child semantics node of the Text; the accessibility delegate hides those children and exposes links as URLSpans on the Text node (for TalkBack's links menu) [https://android.googlesource.com/platform/frameworks/support/+/refs/heads/androidx-main/compose/ui/ui/src/androidMain/kotlin/androidx/compose/ui/platform/AndroidComposeViewAccessibilityDelegateCompat.android.kt, checked 2026-11-28]
- A parent `clickable` merges children, but a child with its own click action defies the merge; mergeDescendants plus a parent onClick keeps the parent click, so test links reachable by TalkBack on a device [https://developer.android.com/develop/ui/compose/accessibility/merging-clearing, checked 2026-11-28]
- Inline images: `appendInlineContent(id, alternateText)` + `BasicText/Text(inlineContent = map)`; `Placeholder(width = 1.em, height = 1.em, ...)` scales with font scale; alternateText must be non-empty, is shown if no content matches, and accessibility uses it to describe the content -> pass ":shortcode:" [https://developer.android.com/reference/kotlin/androidx/compose/foundation/text/package-summary, https://developer.android.com/reference/kotlin/androidx/compose/foundation/text/InlineTextContent, checked 2026-11-28]
- `LocalBackgroundTextMeasurementExecutor` lets BasicText premeasure on a background executor in lazy lists; benchmark first, null by default [https://developer.android.com/reference/kotlin/androidx/compose/foundation/text/package-summary, checked 2026-11-28]
