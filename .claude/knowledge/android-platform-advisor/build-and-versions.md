# Build and versions (checked 2026-11-27)

- AGP 9.5.1 is the latest stable; needs Gradle 9.6.0+, JDK 17 (minimum and default), supports up to API 37; API 37.0 needs AGP 9.1.1+ [https://developer.android.com/build/releases/gradle-plugin, https://developer.android.com/build/releases/about-agp, 2026-11-27]
- Gradle current release is 9.9.2 (2026-11-19) [https://services.gradle.org/versions/current, 2026-11-27]
- AGP 9 built-in Kotlin: do not apply org.jetbrains.kotlin.android; kapt -> KSP or com.android.legacy-kapt; kotlin jvmTarget defaults to compileOptions.targetCompatibility; AGP 9.0-9.5 pulls KGP 2.2.10, so declare the compose or serialization plugin at a newer version to align KGP [https://developer.android.com/build/migrate-to-built-in-kotlin, 2026-11-27]
- Kotlin 2.4.21 latest stable (2026-10-08); KSP 2.3.14 (KSP versions no longer tied to Kotlin); kotlinx-serialization-json 1.13.0 [https://kotlinlang.org/docs/releases.html, https://repo1.maven.org/maven2/com/google/devtools/ksp/com.google.devtools.ksp.gradle.plugin/maven-metadata.xml, https://repo1.maven.org/maven2/org/jetbrains/kotlinx/kotlinx-serialization-json/maven-metadata.xml, 2026-11-27]
- compileSdk DSL: `compileSdk { version = release(37) { minorApiLevel = 1 } }`; the manifest cannot target a minor SDK, targetSdk is the integer 37; Android 17 = API 37 [https://developer.android.com/reference/tools/gradle-api/9.1/com/android/build/api/dsl/CompileSdkSpec, https://developer.android.com/guide/topics/manifest/uses-sdk-element, 2026-11-27]
