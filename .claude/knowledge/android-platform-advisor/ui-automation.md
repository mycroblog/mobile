# UiAutomation and accessibility tree (instrumented runner)

- `UiAutomation.getWindows()` and `getWindowsOnAllDisplays()` (API 30) return windows only if `AccessibilityServiceInfo.FLAG_RETRIEVE_INTERACTIVE_WINDOWS` is set; `findFocus` falls back to the active window without it -> set it via `getServiceInfo()` then `setServiceInfo()` [https://developer.android.com/reference/android/app/UiAutomation, checked 2026-11-27]
- uiautomator `UiDevice.getUiAutomation()` calls `instr.getUiAutomation(flags)`, then ORs FLAG_RETRIEVE_INTERACTIVE_WINDOWS into `serviceInfo.flags` and toggles FLAG_INCLUDE_NOT_IMPORTANT_VIEWS with `setServiceInfo` -> windows are enabled once `UiDevice` fetched it; a raw `instr.uiAutomation` does not get it [androidx-main UiDevice.java, https://cs.android.com/androidx/platform/frameworks/support/+/androidx-main:test/uiautomator/uiautomator/src/main/java/androidx/test/uiautomator/UiDevice.java, checked 2026-11-27]
- `AccessibilityNodeInfo` has no public roleDescription getter in the reference; `AccessibilityNodeInfoCompat.getRoleDescription()` (core 1.1.0) reads extras CharSequence `"AccessibilityNodeInfo.roleDescription"` -> use `AccessibilityNodeInfoCompat.wrap(node)` or that key [https://developer.android.com/reference/androidx/core/view/accessibility/AccessibilityNodeInfoCompat, checked 2026-11-27]
- Compose sets roleDescription only for Role.Tab and Role.Switch (localized strings); other roles set className from `role.toLegacyClassName()` (Image only for an unmerged leaf or merging descendants); `SemanticsPropertiesAndroid.AccessibilityClassName` overrides; `heading()` sets `isHeading`; defaults android.view.View, TextView, EditText, SeekBar, ProgressBar, ScrollView -> AndroidComposeViewAccessibilityDelegateCompat.android.kt in androidx compose ui [https://cs.android.com/androidx/platform/frameworks/support/+/androidx-main:compose/ui/ui/src/androidMain/kotlin/androidx/compose/ui/platform/AndroidComposeViewAccessibilityDelegateCompat.android.kt, checked 2026-11-27]
- `UiAutomation.executeShellCommand` runs like `adb shell`, returns stdout as a ParcelFileDescriptor the caller must close; uiautomator marks `UiDevice.executeShellCommand` @Discouraged for `executeShellCommandRwe` (API 34, adds stderr) [https://developer.android.com/reference/android/app/UiAutomation, checked 2026-11-27]
