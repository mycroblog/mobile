# Layout by window, not device (checked 2026-11-27)

- Size classes: width compact <600, medium <840, expanded <1200, large <1600, extra-large >=1600 dp; height compact <480, medium <900, expanded >=900; "explicitly not determined by the size of the device screen", not for isTablet logic; large/XL need currentWindowAdaptiveInfo(supportLargeAndXLargeWidth = true) [https://developer.android.com/develop/ui/compose/layouts/adaptive/use-window-size-classes, 2026-11-27]
- API: androidx.compose.material3.adaptive.currentWindowAdaptiveInfo().windowSizeClass, type androidx.window.core.layout.WindowSizeClass, check with isWidthAtLeastBreakpoint / isHeightAtLeastBreakpoint (WindowSizeClass.WIDTH_DP_MEDIUM_LOWER_BOUND, HEIGHT_DP_MEDIUM_LOWER_BOUND) [same URL, 2026-11-27]
- Lint ConfigurationScreenWidthHeight (warning, Correctness, priority 3, Compose UI lint) flags Configuration.screenWidthDp/screenHeightDp (incl. via LocalConfiguration.current), says use LocalWindowInfo.current.containerSize; it does not flag smallestScreenWidthDp, orientation, screenLayout [https://android.googlesource.com/platform/frameworks/support/+/refs/heads/androidx-main/compose/ui/ui-lint/src/main/java/androidx/compose/ui/lint/ConfigurationScreenWidthHeightDetector.kt, 2026-11-27]
- Lint LockedOrientationActivity (warning, manifest android:screenOrientation locked) and SourceLockedOrientationActivity (warning, setRequestedOrientation locking) exist; DiscouragedApi (warning) covers APIs annotated discouraged, not shown to cover orientation or Display size APIs [https://googlesamples.github.io/android-custom-lint-rules/checks/LockedOrientationActivity.md.html, https://googlesamples.github.io/android-custom-lint-rules/checks/SourceLockedOrientationActivity.md.html, 2026-11-27]
- WindowInfo.containerSize/containerDpSize (compose ui 1.8.0): window size, "generally the correct signal to drive the overall layout structure" though not inset-free [https://developer.android.com/reference/kotlin/androidx/compose/ui/platform/WindowInfo, 2026-11-27]
