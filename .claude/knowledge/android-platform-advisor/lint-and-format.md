# Kotlin format and Android Lint (checked 2026-11-27)

- ktlint 1.8.0 is the latest; CLI artifact com.pinterest.ktlint:ktlint-cli:1.8.0 with classifier `all` (ktlint-cli-1.8.0-all.jar, sha256 369ad2b789f95a011f807e1fcb690ccef80bd7cd014fd139e73ae82dcc0baeab) -> pin the jar by hash [https://repo1.maven.org/maven2/com/pinterest/ktlint/ktlint-cli/1.8.0/, 2026-11-27]
- ktlint CLI: `-F`/`--format` fixes; globs are gitignore-style, `!` negates (`'**/*.kt' '!**/generated/**'`); hidden folders skipped; reads every .editorconfig; `ktlint_code_style = ktlint_official|intellij_idea|android_studio` [https://github.com/pinterest/ktlint/blob/1.8.0/documentation/snapshot/docs/install/cli.md, https://github.com/pinterest/ktlint/blob/1.8.0/documentation/snapshot/docs/rules/code-styles.md, 2026-11-27]
- ktlint code styles: android_studio is "based on Android's Kotlin styleguide" (4-space indent, 100 columns, no wildcard imports in the guide); ktlint_official (default) combines Kotlin conventions and that guide and may differ from the Android Studio formatter [same URLs, https://developer.android.com/kotlin/style-guide, 2026-11-27]
- ktlint-gradle (org.jlleitschuh.gradle.ktlint) 14.2.0 (2026-03-12); built-in Kotlin support added in 14.1.0 (older ones created no tasks without kotlin-android) [https://github.com/JLLeitschuh/ktlint-gradle/releases, 2026-11-27]
- Other formatter versions: ktfmt 0.64 (com.facebook:ktfmt), Spotless plugin 8.12.0 [https://repo1.maven.org/maven2/com/facebook/ktfmt/ktfmt/maven-metadata.xml, https://plugins.gradle.org/m2/com/diffplug/spotless/spotless-plugin-gradle/maven-metadata.xml, 2026-11-27]
- Lint DSL (AGP 9.1 reference): abortOnError, warningsAsErrors, checkReleaseBuilds (default true, fatal only), baseline, checkDependencies (default false), ignoreTestSources, checkGeneratedSources (lint skips generated sources unless true) [https://developer.android.com/reference/tools/gradle-api/9.1/com/android/build/api/dsl/Lint, 2026-11-27]
- Lint is not run by the build: "explicitly run lint as part of a continuous integration build"; `./gradlew lint` runs the default variant (lintDebug); baseline made by running with -Dlint.baselines.continue=true; lint.xml supports `<issue id><ignore path/></issue>` [https://developer.android.com/studio/write/lint, 2026-11-27]
- com.android.lint (LintPlugin, since AGP 8.0.2) runs lint "without the Android Gradle plugin, such as in a pure Kotlin project" [https://developer.android.com/reference/tools/gradle-api/9.1/com/android/build/gradle/LintPlugin, 2026-11-27]
