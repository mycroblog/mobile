# Scroll geometry, GRDB 7.12 API, AsyncImage

- onScrollGeometryChange(for:of:action:) iOS 18+: `of: (ScrollGeometry) -> T` (T Equatable), `action: (old, new)`; only the first scroll view in the hierarchy reports. ScrollGeometry (iOS 18+) has contentOffset (CGPoint, may leave 0...content under insets/rubber banding), contentInsets (EdgeInsets), containerSize; offset + containerSize = visible rect [https://developer.apple.com/documentation/swiftui/view/onscrollgeometrychange(for:of:action:), https://developer.apple.com/documentation/swiftui/scrollgeometry/contentoffset, checked 2026-11-28]
- onGeometryChange(for:of:action:) iOS 16+ with `of: (GeometryProxy) -> T`; GeometryProxy.frame(in:) and `.scrollView` (innermost scroll view's coordinate space) are iOS 17+ -> a row's frame in its scroll view [https://developer.apple.com/documentation/swiftui/view/ongeometrychange(for:of:action:), https://developer.apple.com/documentation/swiftui/coordinatespaceprotocol/scrollview, checked 2026-11-28]
- ScrollPosition.scrollTo(y:) clamps to content, scrollTo(id:anchor:) needs scrollTargetLayout; no page says two calls in a row compose an offset after an id -> test [https://developer.apple.com/documentation/swiftui/scrollposition/scrollto(y:), checked 2026-11-28]
- GRDB 7.12: `DatabasePool(path:configuration:)`, `DatabaseQueue(path:)`, in-memory `DatabaseQueue()` / `DatabaseQueue(named:)` (init(named: String? = nil, configuration:) throws); `var m = DatabaseMigrator(); m.registerMigration("v1"){db in}; try m.migrate(writer)` (migrate(_ writer: any DatabaseWriter), DatabaseMigrator is Sendable) [https://github.com/groue/GRDB.swift/blob/v7.12.0/GRDB/Core/DatabaseQueue.swift, .../Documentation.docc/Migrations.md, checked 2026-11-28]
- GRDB 7.12: `ValueObservation.tracking(_ fetch: @escaping @Sendable (Database) throws -> Value)`; `.values(in: any DatabaseReader, scheduling: = .task, bufferingPolicy: = .unbounded)` returns AsyncValueObservation<Element: Sendable> -> the observed value, so records, must be Sendable [https://github.com/groue/GRDB.swift/blob/v7.12.0/GRDB/ValueObservation/ValueObservation.swift, checked 2026-11-28]
- GRDB Codable records: non-value properties (arrays, structs) become JSON strings, Data stays blob; override `static func databaseJSONEncoder(for column:) -> JSONEncoder` (and Decoder); set `sortedKeys` so ValueObservation sees stable output [https://github.com/groue/GRDB.swift/blob/v7.12.0/README.md#json-columns, checked 2026-11-28]
- AsyncImage (iOS 15+) uses URLSession.shared, which uses URLCache.shared; only iOS 27+ documents AsyncImage caching and asyncImageURLSession(_:); no page documents LazyVStack reload on reappear -> on iOS 26 assume no guaranteed cache, use own loader [https://developer.apple.com/documentation/swiftui/asyncimage, https://developer.apple.com/documentation/foundation/urlsession/shared, checked 2026-11-28]
