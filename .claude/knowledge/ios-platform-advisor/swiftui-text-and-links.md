# SwiftUI Text composition, attributes, links

- `Text + Text` (`+(_:_:)`) is deprecated since iOS 26 SDK (iOS 13-26 range; not visionOS): "hardcodes a specific order ... may lead to incorrect localization"; use `Text("Hello, \(name)!")` -> compose runs by interpolating Text into a LocalizedStringKey literal [https://developer.apple.com/documentation/swiftui/text/+(_:_:), checked 2026-11-28]
- Text overview: to style only parts of interpolated text, "interpolate `Text` or AttributedString" (`appendInterpolation(_ text: Text)`, iOS 14+); Image interpolates the same way (iOS 14+); the page does not say whether `.link` runs of an interpolated Text stay tappable -> test on device [https://developer.apple.com/documentation/swiftui/text, https://developer.apple.com/documentation/swiftui/localizedstringkey/stringinterpolation/appendinterpolation(_:)-4qyfo, checked 2026-11-28]
- Text(AttributedString) (iOS 15+) renders all InlinePresentationIntent values except lineBreak and softBreak (so stronglyEmphasized, emphasized, strikethrough, code are drawn), respects writingDirection, draws `link` as a link opened via openURL; "ignores any other Foundation-defined attributes"; SwiftUIAttributes (underlineStyle, iOS 15+) win over equivalents [https://developer.apple.com/documentation/swiftui/text/init(_:)-1a4oh, https://developer.apple.com/documentation/foundation/attributescopes/swiftuiattributes/underlinestyle, checked 2026-11-28]
- Text.baselineOffset(_:) (iOS 13+, returns Text): moves text in points, view bounds grow to contain it; documented for text only, no page ties it to an interpolated Image. Image.resizable inside Text, and frame on it, are not documented; no pre-render-a-UIImage guidance found -> test [https://developer.apple.com/documentation/swiftui/text/baselineoffset(_:), checked 2026-11-28]
- SFSafariViewController (iOS 9+): "Present it modally using present(_:animated:completion:)", never embed as child; formSheet/pageSheet only for terms or support docs, not for website content; no SwiftUI view, so UIViewControllerRepresentable (iOS 13+) is the SwiftUI bridge; Apple names no preference between sheet and window-root present; the pages read do not list accepted URL schemes [https://developer.apple.com/documentation/safariservices/sfsafariviewcontroller, https://developer.apple.com/documentation/swiftui/uiviewcontrollerrepresentable, checked 2026-11-28]
