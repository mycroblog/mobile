# Extensions

- Notification Service Extension: about 30 s in didReceive, then serviceExtensionTimeWillExpire; only for alert pushes with mutable-content 1; if neither handler completes, the original content shows -> always complete with a fallback [https://developer.apple.com/documentation/usernotifications/modifying-content-in-newly-delivered-notifications, checked 2026-11-27]
- Notification Service Extension memory cap about 24 MB (undocumented) -> link only small packages [https://developer.apple.com/forums/thread/807554, checked 2026-11-27]
- Share Extension memory cap about 120 MB (undocumented); the system may end it right after completeRequest -> long uploads go to a background URLSession with sharedContainerIdentifier; completion relaunches the app via handleEventsForBackgroundURLSession [https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/ExtensionScenarios.html, checked 2026-11-27]
- Keychain sharing needs a shared access group (entitlement or App Group); the first listed group is the default; a group the target is not entitled to fails with errSecMissingEntitlement [https://developer.apple.com/documentation/security/sharing-access-to-keychain-items-among-a-collection-of-apps, checked 2026-11-27]
- Default accessibility is WhenUnlocked; reading while locked needs AfterFirstUnlock (use the ThisDeviceOnly variant to avoid backup and sync) [https://developer.apple.com/documentation/security/restricting-keychain-item-accessibility, checked 2026-11-27]
- RFC 8291 aes128gcm: salt and the sender key come from the header; ECDH plus the 16-byte auth secret give the IKM; padding delimiter 0x02 -> keep a P-256 key pair and auth secret per subscription [https://www.rfc-editor.org/rfc/rfc8291.html, checked 2026-11-27]
- App Intents should change the UI from scene code; TargetContentProvidingIntent routes to scenes via handlesExternalEvents, from iOS 26; needs UIApplicationSupportsMultipleScenes [https://developer.apple.com/documentation/appintents/directing-app-intents-to-your-apps-scenes, checked 2026-11-27]
