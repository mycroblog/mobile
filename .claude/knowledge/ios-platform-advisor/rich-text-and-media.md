# Rich text, accessibility, media

- NSAttributedString(data:options:) with documentType html: not from a background thread (tries to sync with main, times out); on main it can still time out on external references; "meant for something like markdown, not general HTML import"; the in-process initializers are discouraged, Apple points to WebKit-based loadFromHTML(request:options:) -> do not use it for post bodies; parse the sanitized HTML ourselves into AttributedString [https://developer.apple.com/documentation/foundation/nsattributedstring/init(data:options:documentattributes:), https://developer.apple.com/documentation/foundation/nsattributedstring/documenttype/html, checked 2026-11-28]
- SwiftUI Text from AttributedString: string attributes win over view modifiers; Text/Link read the openURL environment, so a custom OpenURLAction (.handled / .systemAction) routes every .link tap [https://developer.apple.com/documentation/swiftui/text, https://developer.apple.com/documentation/swiftui/environmentvalues/openurl, checked 2026-11-28]
- Inline images in Text: Apple's Text page documents only Image interpolation in a LocalizedStringKey (iOS 14+, "don't call directly") and Text + Text; it documents no attachment or custom-emoji API for Text, and no iOS 27 addition was found (no page on Image scaling inside Text read) -> custom emoji inline is not a documented SwiftUI feature; test Dynamic Type on device [https://developer.apple.com/documentation/swiftui/localizedstringkey/stringinterpolation/appendinterpolation(_:)-5m52e, checked 2026-11-28]
- NSAdaptiveImageGlyph (iOS 18+): emoji-like image for attributed text with contentDescription; created by the text-input system, built from HEIC-like imageContent Data; Apple documents it for TextKit, not for SwiftUI Text [https://developer.apple.com/documentation/uikit/nsadaptiveimageglyph, checked 2026-11-28]
- ScaledMetric(relativeTo:) scales a number with Dynamic Type (iOS 14+) -> size an emoji image with it; Image(decorative:) is ignored by VoiceOver, Image(_:label:) is spoken [https://developer.apple.com/documentation/swiftui/scaledmetric, https://developer.apple.com/documentation/swiftui/image, checked 2026-11-28]
- accessibilityElement(children: .combine) merges a row; accessibilityAction(named:) (iOS 16+) adds named actions; accessibilityRotor(_:entries:entryID:entryLabel:) (iOS 16+) must attach to a ScrollView or an element in it and scrolls the entry into place; no page read says Text links get an automatic rotor [https://developer.apple.com/documentation/swiftui/view/accessibilityelement(children:), https://developer.apple.com/documentation/swiftui/view/accessibilityaction(named:_:), https://developer.apple.com/documentation/swiftui/view/accessibilityrotor(_:entries:entryid:entrylabel:), checked 2026-11-28]
- accessibilityReduceMotion (iOS 13+, name unchanged in 2026 docs): "avoid large animations"; no page says animated GIF/APNG/video autoplay is stopped for you -> gate animated emoji and gifv on it yourself [https://developer.apple.com/documentation/swiftui/environmentvalues/accessibilityreducemotion, checked 2026-11-28]
- AVAssetImageGenerator (iOS 4+): async image(at:) -> CGImage, maximumSize; no Apple API decodes blurhash (none found in Apple docs) [https://developer.apple.com/documentation/avfoundation/avassetimagegenerator, checked 2026-11-28]
