# Concurrency and build

- View is MainActor; some closures (visualEffect, onGeometryChange) may run off the main actor [https://developer.apple.com/videos/play/wwdc2025/266/, checked 2026-11-27]
- With Xcode 27, @State initializes an Observable class once per view lifetime, back-deployed; earlier builds may run the initializer repeatedly [https://developer.apple.com/videos/play/wwdc2026/269/, checked 2026-11-27]
- iOS 27 SDK requires the UIScene life cycle [https://developer.apple.com/videos/play/wwdc2026/278/, checked 2026-11-27]
- Xcode 26 explicitly built modules: reports of "Unable to find module dependency" across local packages (Apple forums) [https://developer.apple.com/forums/thread/806875, checked 2026-11-27]
- Xcode 27.2 and swift build 6.4.2 (default swiftbuild engine, explicit modules on): an undeclared sibling import fails ("Unable to resolve module dependency") only when the sibling is not already built in that build dir; if built first (other scheme, same DerivedData) it compiles -> check each target with a clean DerivedData per scheme, not one all-targets build (observed, undocumented, 2026-11-27)
- `swift build --explicit-target-dependency-import-check error` exists in 6.4.2 but only the deprecated `--build-system native` honors it (same-package targets only: "imports another target in the package without declaring it"); the default swiftbuild engine ignores it; no xcodebuild setting exists (SWIFT_ENABLE_EXPLICIT_MODULES only toggles explicit module tasks, and NO lets the undeclared import build) (observed 2026-11-27; SwiftBuild Swift.xcspec in Xcode 27.2)
- PackageDescription 6.4.2 interface: `defaultIsolation(_ isolation: MainActor.Type?, _ condition: BuildSettingCondition? = nil)`, available tools-version 6.2; `.defaultIsolation(nil)` = nonisolated, which is also the default when omitted -> per-target `.defaultIsolation(MainActor.self)` for UI modules [PackageDescription.swiftinterface in Xcode 27.2 toolchain, checked 2026-11-27]
- App target: SWIFT_DEFAULT_ACTOR_ISOLATION = nonisolated | MainActor (default nonisolated); new Xcode 26 app projects get MainActor and Approachable Concurrency; Apple: MainActor for app and UI modules, nonisolated for general-purpose libraries; recommends all projects adopt Approachable Concurrency [https://developer.apple.com/videos/play/wwdc2025/268/, checked 2026-11-27]
- SWIFT_APPROACHABLE_CONCURRENCY applies only in Swift 4/4.2/5 language mode (xcspec Condition); in Swift 6 mode set SWIFT_UPCOMING_FEATURE_NONISOLATED_NONSENDING_BY_DEFAULT and _INFER_ISOLATED_CONFORMANCES = YES individually; in packages use enableUpcomingFeature("NonisolatedNonsendingByDefault") (Swift.xcspec in Xcode 27.2, checked 2026-11-27)
- A dependency resolving a swift-syntax version other than Xcode's prebuilt one rebuilds swift-syntax from source (minutes per build) -> check Package.resolved [https://developer.apple.com/forums/thread/836382, checked 2026-11-27]
- An xcodebuild of the app accepted a local package importing a package outside its dependencies once that module was built in the same DerivedData; a build of that package alone with its own -derivedDataPath refused it ("Unable to resolve module dependency") clean and incremental; a module reachable through a declared dependency always compiles [observed Xcode 27.2, 2026-11-27]
