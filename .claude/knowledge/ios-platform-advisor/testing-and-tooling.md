- Xcode 27.2 `xcrun xcresulttool export attachments --path P --output-path D [--test-id ID] [--filter GLOB] [--only-failures]` exports all attachments unless filtered; manifest.json (schema 0.5.0) = array of {testIdentifier, testIdentifierURL, attachments:[{exportedFileName, suggestedHumanReadableName, isAssociatedWithFailure, timestamp, configurationName, deviceName, deviceId, repetitionNumber, arguments}]} [`--help`, `--schema` of Xcode 27.2, checked 2026-11-27]
- xcodebuild: env `TEST_RUNNER_<VAR>` reaches, prefix stripped, all test runner processes of a test action; observed reaching a package test bundle (scheme run, simulator) incl. SNAPSHOT_* [`man xcodebuild`; observed in #10, 2026-11-27]
- xcodebuild flags: `-parallel-testing-enabled NO` overrides the scheme; `-disable-concurrent-destination-testing` runs destinations in turn; `-maximum-concurrent-test-simulator-destinations N` caps simulators; with the first two plus `-destination id=<booted udid>` no clone was booted [`man xcodebuild`; observed in #10, 2026-11-27]
- ATS `NSAllowsLocalNetworking` covers unqualified domains (`localhost`), `.local`, IP addresses; since iOS 17 IP addresses are not allowed by default (list them in NSExceptionDomains); `http://localhost:8790` from a package test bundle without host app on the iOS 27.2 simulator was not blocked [https://developer.apple.com/documentation/bundleresources/information-property-list/nsapptransportsecurity/nsallowslocalnetworking, checked 2026-11-27; observed in #10, 2026-11-27]
- `export attachments --only-failures` dropped snapshot-testing's reference/failure/difference PNGs under Swift Testing (only "Complete Issue Description.txt" left); without it they export, named `difference_0_<uuid>.png`, `failure_...`, `reference_...` (suggestedHumanReadableName) [observed in #10, Xcode 27.2, 2026-11-27]
- Package test bundle without host app: SwiftUI TabView's Liquid Glass tab bar renders empty in `.image(layout: .device)`; `drawHierarchyInKeyWindow: true` traps "requires tests to be run in a host application" [observed in #10, iOS 27.2 simulator, 2026-11-27]
- OpenAPIRuntime default ISO8601DateTranscoder rejects "2026-11-27T11:19:24.134Z" (fractional seconds) [observed in #10, 2026-11-27]
