# ADR-0001: ライセンス

- Status: Accepted
- Date: 2026-11-27
- Deciders: @rosylilly

## Decision (決定)

### 1. Apache License 2.0

コードは公開して開発し、Apache-2.0 で配布する。

- App Store と Google Play で配布できる。GPL 系のライセンスは、ストアの利用条件と両立しないおそれがある。
- 特許の許諾が条文にあり、貢献者にも外部の利用者にも扱いが明確になる。
- §6 は商標を許諾しない。そのため、フォークに mycroblog の名前を使わせない線引きができる。

### 2. ブランドの資産は分ける

ロゴ、アプリのアイコン、名前などのブランドの資産は、Apache-2.0 の対象から外す。置き場所とその条件は、資産を足すときに決めて README に書く。

### 3. サーバーのリポジトリからの流用

- `my` 本体は AGPL-3.0 なので、コード、翻訳のカタログ、UI の文言を写さない。
- 流用してよいのは、MIT で配布されているものだけである (API の仕様、クライアントとボットのライブラリ、プラグインの定義。my ADR-0093 §2)。今使うのは API の仕様だけで、ライブラリの振る舞いは参考にするが、コードは写さない。
- 振る舞いは、仕様と文書を読んで書き直す。

## 採らなかった案

- MIT: 最も簡素で、API の仕様と揃う。しかし特許と商標について何も定めない。
- MPL-2.0: ファイル単位で改変の還元を求められ、ストアとも両立した例がある。しかし外部の貢献者にとって扱いが重い。
- AGPL-3.0 (サーバーと揃える): ストアでの配布と両立させるのが難しい。

## 見直す条件

- `my` の該当部分が許容的なライセンスで再許諾され、流用できる範囲が変わったとき。
